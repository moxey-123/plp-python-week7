# Week 7 Assignment: My Notes & The Report Builder

## Project Description
This assignment demonstrates Python file handling and CSV data processing.

## Project Files

- **my_notes.py** – Writes, appends, reads, and counts notes.
- **my_notes.txt** – Stores the four notes.
- **report_builder.py** – Reads CSV data and generates a learner report.
- **hubs.csv** – Contains learner names, hubs, and scores.
- **report.txt** – Contains the generated learner report.

## File Handling Explanation

If I change `"a"` to `"w"` in Question 1, Python will erase the existing notes before writing the new note. The first three notes will be lost, leaving only the fourth note.

## Expected Report

- Total learners: 5
- Passed: 3
- Failed: 2
- Average score: 63.2

## Technologies Used
- Python
- CSV
- File Handling
